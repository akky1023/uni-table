# うに時間割

大学生向けの時間割・課題管理アプリ．大学生向けと銘打ってはいますが，小中高生も使おうと思えば使えるはずです．

アプリ自体は完全ローカルで動くことを目指してはいますが，祝日データ等の更新にインターネット接続が必要になる予定です．

また，データ自体は自分で場所をいじれますから，syncthingとか，nextcloudとかつかって好きに同期しちゃってください．

## 対応環境・配布

- Android: Android 8.0（API 26）以上
- Windows: Windows 10 / 11、x64

Androidは端末に合うAPKを1つインストールしてください．

64bit ARM端末は`arm64-v8a`，32bit ARM端末は`armeabi-v7a`，x86の64bit端末・エミュレーターは`x86_64`を選びます．最近のスマホはだいたい`arm64-v8a`です．

ビルド済みファイルはリリースからダウンロードしてください．
[Releases](https://github.com/akky1023/uni-table/releases)

## データの保存

KeePass使用者は慣れていると思います．

初回起動時に，`.unitable`ファイルを選択または新規作成します．次回からは選択したファイルを開きます．設定から変更可能です．

`.unitable`は拡張子が変わっただけのSQLiteです．時間割・課題・年間予定を保存します．設定と選択したファイルの場所は各端末に保存します．

このアプリ自体にクラウド同期機能はありません，自前で用意してください．`.unitable`自体はAndroidとWindowsどちらでも読み込めます．

データベースの上限は32 MiB・合計100,000件 (時間枠などの内部レコードを含む) です．上限を超えるファイルや，アプリが使用しないトリガー・ビュー・SQL定義を含むファイルは開きません．

バックアップは`.unitable`ファイルのコピーで行えます．旧形式のファイルは読み込み時に移行されるため，グレードダウンができません．更新前のバックアップを推奨します．
